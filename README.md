# ICHydro documentation

This repository configures centralised documentation for software outputs from the Hydrology and Water Resources Lab at Imperial College London.

## Contents

The documentation enables users to search across all ICHydro resources in one centralised location and is available in both English and Spanish. Documentation for individual repositories is imported using the [`mkdocs-multirepo-plugin`](https://github.com/jdoiro3/mkdocs-multirepo-plugin).
