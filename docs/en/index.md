This is the centralised documentation repository for software outputs from the [Hydrology and Water Resources Lab](https://ichydro.github.io/) at Imperial College London.

This site provides documentation for the following tools:

- [**Paricia**](https://imperialcollegelondon.github.io/paricia/en/): a hydroclimactic data management system
- [**Riverlabs**](https://ichydro.github.io/Riverlabs/): our suite of low-cost environmental loggers

Follow the links to access the full source documentation, including complete API references.
