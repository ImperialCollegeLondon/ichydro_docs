Este es el repositorio centralizado de documentación para los productos de software del [Laboratorio de Hidrología y Recursos Hídricos](https://ichydro.github.io/) del Imperial College London.

Este sitio proporciona documentación para las siguientes herramientas:

- [**Paricia**](https://imperialcollegelondon.github.io/paricia/es/): un sistema de gestión de datos hidroclimáticos
- [**Riverlabs**](https://ichydro.github.io/Riverlabs/index_es.html): nuestro conjunto de registradores ambientales de bajo costo

Siga los enlaces para acceder a la documentación completa del código fuente, incluidas las referencias completas de la API.
